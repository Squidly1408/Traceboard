A free image to SVG converter that runs entirely in your browser

Traceboard turns a photo, logo, or sketch into clean, scalable vector paths. Trace by hand with a real bezier pen tool, sketch freehand with the pencil, or let auto-trace take a first pass — then export standard SVG you can drop straight into any project. No account, no upload to a server, no software to install.

What you can do with Traceboard

  • Bezier pen tool

    Click for sharp corners, drag for smooth curves — the same anchor-and-handle workflow as professional vector editors.

  • Freehand pencil

    Draw naturally and Traceboard simplifies and smooths your stroke into a clean curve automatically.

  • One-click auto-trace

    Get a rough vectorization of a whole image instantly, then refine it by hand.

  • Layer-aware fills

    Shapes drawn on top correctly punch holes in shapes beneath them, so rings, cutouts, and compound shapes just work.

  • Reference image underlay

    Trace over your source image at adjustable opacity — it's a guide only and is never included in the export.

  • Clean SVG export

    Download or copy dependency-free SVG markup, ready to use anywhere.

How it works

  1. Upload a reference image — drag and drop a photo, logo, or sketch onto the canvas.
  2. Trace it — use the pen or pencil tool, or run auto-trace for a quick starting point.
  3. Style your paths — set stroke color and width, or fill color, per path.
  4. Export — download an SVG file or copy the markup straight to your clipboard.

Frequently asked questions

Is Traceboard free to use?

Yes. Traceboard is completely free, with no sign-up and no limits on how many images you trace or export.

Do my images get uploaded anywhere?

No. Traceboard runs entirely in your browser — your reference image and traced paths never leave your device, except when you use Auto-trace, which loads a small open-source tracing library from a CDN but still processes your image locally.

What image formats can I trace?

Any common raster format your browser can display, including PNG, JPG, and WEBP, works as a tracing reference.

What file format does Traceboard export?

Traceboard exports standard, dependency-free SVG — clean vector paths you can open in any vector editor or drop straight into a website or app.

Can I use Traceboard offline?

Yes. Once loaded, the Pen and Pencil tracing tools work fully offline, and Traceboard can be installed as an app for quick access. Auto-trace needs an internet connection the first time it's used.

Traceboard is open source. View the code or file an issue on GitHub.
